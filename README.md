# Daily Task Reminders

A simple task-management website built using HTML, CSS and JavaScript to help users organise and track their daily activities.

### Features
- Login with name
- Add tasks with due dates, categories and priorities
- Search and filter tasks
- Mark tasks as completed
- Delete tasks
- Dashboard showing total, pending and completed tasks
- Save tasks using browser Local Storage
- Responsive layout

### Technologies Used
- **HTML:** Website structure
- **CSS:** Styling, layout and animations
- **JavaScript:** Functionality and interactivity
- **Local Storage:** Saving task data

### How to Use
1. Enter your name to log in.
2. Add a task with its due date, category and priority.
3. Search or filter your tasks.
4. Mark tasks as completed or delete them.
5. Track your progress through the dashboard.

### Project Structure
- `index.html` – Contains the HTML, CSS and JavaScript code.
- `README.md` – Project documentation.

### Objective
To create an interactive and user-friendly website that helps users manage their daily tasks efficiently.
